# React Formulaire

A React form project created as a frontend development exercise. The form implementation is located in `src/Component/formul.jsx`.

## Run locally
```bash
npm install
npm start
```

## Project structure
- `src/Component/formul.jsx` — form component
- `src/App.js` — application entry component
- `src/App.css` — application styling

## Stack
React · JavaScript · JSX · CSS

> Coursework project. Original application source files are preserved.
