## Getting started

Clone the repository:

```bash
git clone https://github.com/enneiymyabdeljalil-ctrl/React_2.git
cd React_2
```

Choose the branch you want to work on:

```bash
git switch tp6-redux
npm install
npm start
```

Replace `tp6-redux` with the branch you want to explore.
