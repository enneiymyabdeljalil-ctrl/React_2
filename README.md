# React 0 — Components & JSX

A React coursework project focused on reusable UI components and JSX structure.

## Run locally
```bash
npm install
npm start
```

## Project structure
- `public/` — static assets
- `src/Components/` — page sections and reusable UI components
- `src/App.js` — application entry component

## Stack
React · JavaScript · JSX · CSS

> Learning project. Original application source files are preserved.
