# React 2 — Counter App

A React counter application built as a frontend development exercise. It uses reusable components and React state to manage counter interactions.

## Run locally
```bash
npm install
npm start
```

## Project structure
- `src/Component/Counter.jsx` — counter interface and behavior
- `src/Component/Valeur.jsx` — value display component
- `src/Component/App.jsx` — component composition

## Stack
React · JavaScript · JSX · CSS
